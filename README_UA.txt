OSMOS DIRECT STICK — GITHUB ACTIONS BUILD KIT
================================================

ПОТОЧНИЙ СТАН: Підготовлено лише файли для хмарної збірки.
Це НЕ скомпільований .nro. Патч не тестувався на Switch.

Як зібрати БЕЗ встановлення devkitPro на комп'ютері:
1. Створіть порожній репозиторій GitHub із гілкою main.
2. Повідомте посилання на репозиторій у чаті — якщо він доступний
   через підключений GitHub, можна додати туди два файли збірки.
   Альтернатива: самостійно завантажити до репозиторію всі файли
   цього архіву, зберігши папки .github/workflows і scripts.
3. Після збереження файлів GitHub Actions запустить збірку або
   запустіть її у вкладці Actions -> Build Osmos Direct Stick for Switch
   -> Run workflow.
4. Якщо збірка пройде, завантажте результат у вкладці Artifacts.
   Файл називатиметься osmos_nx.nro.

ЛИШЕ ПІСЛЯ ОТРИМАННЯ NRO:
- Зробіть резервну копію оригінального файлу SD:/switch/osmos/osmos_nx.nro.
- Замініть тільки osmos_nx.nro. NSP не потрібно замінювати.
- R3: режим напрямку, лівий стік: напрямок, ZR: поштовх.
- R3 повторно: повернути звичайний курсор для меню.
- Для повернення попередньої версії відновіть резервний osmos_nx.nro.

ВАЖЛИВО: це експериментальний режим, який імітує дотик від центру
екрана (а не точного положення кульки). Напрямок може бути неточним.
GitHub Actions потрібне з'єднання з інтернетом. Збірка у GitHub ще
не запускалася, тому її успішність наразі не підтверджена.

Код оригінального порту: https://github.com/ChanseyIsTheBest/osmos_nx
